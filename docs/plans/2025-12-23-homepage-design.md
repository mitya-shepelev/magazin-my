# Дизайн главной страницы Digital Store

**Дата:** 2025-12-23
**Статус:** Утверждён

## Концепция

**Посыл:** "Готовые решения от экспертов" — экономия времени разработки + надёжность и поддержка.

**Стиль:** Premium Dark Tech с emerald/cyan акцентами, glassmorphism, анимации.

---

## Секции

### 1. Hero

**Структура:** Два столбца (60/40), одна колонка на мобильных.

**Левая часть:**
- Badge: "Готовые решения для бизнеса"
- H1: "Веб-приложения от экспертов"
- Подзаголовок: "Экономьте месяцы разработки..."
- Кнопки: "Смотреть каталог" (primary) + "Как это работает" (outline)
- Мини-статистика: "50+ продуктов • 500+ клиентов • 4.9 рейтинг"

**Правая часть:**
- Floating карточка товара (самый популярный)
- Glassmorphism, glow-border, float-анимация

**Фон:** gradient-mesh + spotlight

---

### 2. Преимущества

**Структура:** 4 карточки в ряд.

1. **Мгновенная доставка** (emerald) — "Получите доступ сразу после оплаты"
2. **Исходный код** (cyan) — "Полный доступ к коду"
3. **Бесплатные обновления** (violet) — "Все будущие версии бесплатно"
4. **Поддержка экспертов** (amber) — "Поможем с установкой и настройкой"

**Стиль:** Glass-карточки, иконка в gradient-круге, hover-lift.

---

### 3. Популярные товары

**Структура:** 3 premium-карточки в ряд.

**Карточка:**
- Glass + glow-border
- Изображение с hover scale
- Badge скидки (shimmer)
- Название, описание, цена (gradient-text)
- Кнопка "Подробнее"

**Данные:** `isFeatured: true`, лимит 3.

---

### 4. Как это работает

**Структура:** 3 шага с соединительной линией.

1. **Выберите продукт** (01) — Search icon
2. **Оплатите онлайн** (02) — CreditCard icon
3. **Скачайте и используйте** (03) — Download icon

**Стиль:** Номера в gradient-кругах, glass-карточки, gradient-линия между шагами.

---

### 5. Отзывы клиентов

**Структура:** 3 карточки отзывов.

**Карточка:**
- Quote icon
- Текст отзыва (italic)
- Аватар (инициалы) + имя + компания
- Рейтинг звёздами

**Модель Prisma:**
```prisma
model Review {
  id        String   @id @default(cuid())
  name      String
  company   String?
  text      String
  rating    Int      @default(5)
  isActive  Boolean  @default(true)
  createdAt DateTime @default(now())
}
```

---

### 6. Категории

**Структура:** 2 большие карточки.

- **Веб-приложения** (Globe icon) — "CRM, магазины, LMS..."
- **Мобильные приложения** (Smartphone icon) — "iOS и Android решения"

**Стиль:** aspect-[2/1], gradient overlay, счётчик товаров, hover glow.

---

### 7. CTA-баннер

**Структура:** Полноширинный баннер.

- Фон: gradient-animate + noise
- "Готовы запустить свой проект?"
- Кнопки: "Смотреть каталог" + "Связаться с нами"

---

## Технические детали

- **Фреймворк:** Next.js 16, App Router
- **Стили:** Tailwind CSS v4, CSS-переменные из globals.css
- **Компоненты:** shadcn/ui + кастомные
- **Данные:** Prisma (products, categories, reviews)
- **Темы:** Светлая по умолчанию, тёмная через next-themes
